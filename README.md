# Upskill

A 24-week, one-hour-a-day study plan for moving into a backend engineering role at an MNC: Java and Spring Boot, DSA, system design, DevOps, AWS, AI engineering, projects and interview prep.

Open the site: https://tejaspatil2295.github.io/Upskill/

Progress is saved in your browser. Use "Move progress between devices" on the Overview tab to carry it to another device.

It is a single static file (`index.html`) with no build step.
